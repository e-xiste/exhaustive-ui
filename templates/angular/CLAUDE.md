## ExhaustiveUI

This project uses ExhaustiveUI (`@exhaustive-ui/core`). Its API is close to PrimeNG but not the same: before writing code with it, read `node_modules/@exhaustive-ui/core/AGENTS.md`, then the card of each component you use. After changing templates, run `npx -y @exhaustive-ui/mcp check`.
